# Script di debug (storici)

Strumenti diagnostici scritti al volo per isolare bug specifici — non fanno
parte della suite di regressione (`tests/run_full_regression.sh` non li
lancia) e i bug che indagavano sono già risolti. Tenuti come riferimento su
come si è arrivati a capire un problema, non come qualcosa da eseguire di
routine. Probabile che smettano di funzionare con le prossime modifiche
(selettori/id che cambiano) senza che sia un problema da correggere.
